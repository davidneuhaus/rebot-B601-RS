Day 2 · Monday, November 16, 2026

The night after – the first training

While we sleep, the Mac mini trains the first ACT policy. Whether it works on the arm, we don't know yet.

⏱ 2 min read · Working time: about 1–2 h active, otherwise overnight run (estimate)

A short chapter, a long night: between roughly 00:00 and 06:00 almost everything ran unattended.

🛠What we did

  • Cleaned up datasets: pick_place_v1 (3 episodes; episode 1 is a failed demo that missed the box – excluded), a clean set pick_place_clean with 6 episodes, and from it the training set pick_place_all7.
  • Overnight training act_pick_place_clean_night1 (ACT): 00:30 to 05:10, so 4:40 h, about 19,960 steps at roughly 1.19 steps per second, loss 0.079. Trained on 5 clean demos (episodes 0, 2, 3, 4, 5).
  • Play bundle v3.4 (05:30): a "play policy" button in the GUI plus play_policy.sh. The dry run ran at 28 Hz, using checkpoint 018000.
  • From about 06:00 first steps toward SmolVLA zero-shot with a text command (v3.5/3.6) – untested on the real arm.
Plot coming soon: loss curve of the overnight run

💭Mindset

We wanted a first end-to-end chain: demonstrations → policy → playback on the arm, so we can test right away in the morning. And: only clean demos count, because imitation learns mistakes too.

🏆Wins

  • The overnight run went through – 4:40 h, loss 0.079.
  • The play button is in place, the dry run runs at 28 Hz.

💥Fails

  • Only 5 demos – very few; the recommendation so far is 30–50 varied demos per task. And the loss says nothing about whether the robot succeeds.
  • The policy has not been tested on the real arm yet.
  • Saving a recording took about 10 s, during which the button felt sluggish.
  • The play bundle could not be installed for a while because approval prompts went unanswered overnight.

📌Learnings

  • Clean, labeled demos matter more than more training steps.
  • Mark failed attempts instead of deleting them – this later became the markers in app 3.8.
  • Overnight runs need approvals cleared in advance.

🔗Sources

LeRobot ACT training, SmolVLA (Hugging Face).
